=======================================
测试用例
=======================================

## 1. client_credentials flow [POST]
URL: http://localhost:8080/oauth2/token

cURL:
curl --location 'http://localhost:8080/oauth2/token' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'client_id=79763e77433640baba722e72c69e25db' \
--data-urlencode 'client_secret=maAXVKPcEvVL37paPC0HTZU48DCG9Lat' \
--data-urlencode 'grant_type=client_credentials' \
--data-urlencode 'scope=openid profile'

响应:
{
  "access_token": "xxx",
  "scope": "openid profile",
  "token_type": "Bearer",
  "expires_in": 3599
}


## 2. authorization_code flow [GET]

(1) 访问授权端点 (浏览器):
http://localhost:8080/oauth2/authorize?response_type=code&client_id=79763e77433640baba722e72c69e25db&scope=openid profile email&redirect_uri=http://localhost:8083/oauth2/callback&state=abc123

登录后重定向到:
http://localhost:8083/oauth2/callback?code=xxx&state=abc123

(2) 获取 code 后换取 token:
curl --location 'http://localhost:8080/oauth2/token' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'client_id=79763e77433640baba722e72c69e25db' \
--data-urlencode 'grant_type=authorization_code' \
--data-urlencode 'code=xxx' \
--data-urlencode 'redirect_uri=http://localhost:8083/oauth2/callback' \
--data-urlencode 'client_secret=maAXVKPcEvVL37paPC0HTZU48DCG9Lat'

响应:
{
  "access_token": "xxx",
  "refresh_token": "xxx",
  "scope": "openid profile email",
  "id_token": "xxx",
  "token_type": "Bearer",
  "expires_in": 3599
}


## 3. refresh_token flow [POST]

curl --location 'http://localhost:8080/oauth2/token' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'client_id=79763e77433640baba722e72c69e25db' \
--data-urlencode 'client_secret=maAXVKPcEvVL37paPC0HTZU48DCG9Lat' \
--data-urlencode 'grant_type=refresh_token' \
--data-urlencode 'refresh_token=xxx'


## 4. userinfo [GET]
(需要通过 authorization_code 流程获取的 token)

curl --location 'http://localhost:8080/userinfo' \
--header 'Authorization: Bearer <ACCESS_TOKEN>'

响应:
{
  "sub": "admin",
  "email": "admin@andaily.com",
  "profile": "xxx"
}


## 5. revoke token [POST]

curl --location 'http://localhost:8080/oauth2/revoke' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'client_id=79763e77433640baba722e72c69e25db' \
--data-urlencode 'client_secret=maAXVKPcEvVL37paPC0HTZU48DCG9Lat' \
--data-urlencode 'token=xxx'

响应: 200 [HTTP]


## 6. introspect token [POST]

curl --location 'http://localhost:8080/oauth2/introspect' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'client_id=79763e77433640baba722e72c69e25db' \
--data-urlencode 'client_secret=maAXVKPcEvVL37paPC0HTZU48DCG9Lat' \
--data-urlencode 'token=xxx'

响应:
{
  "active": true,
  "scope": "openid profile",
  "client_id": "79763e77433640baba722e72c69e25db",
  "token_type": "Bearer",
  "exp": 1697724263,
  "iat": 1697720663
}
